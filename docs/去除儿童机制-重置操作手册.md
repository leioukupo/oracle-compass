# MAGNEO C110001 去除儿童机制 · 重置系统操作手册

> 适用机型：MAGNEO C110001（MT6580 / Android 5.1 / 800×800 圆屏）
> 结论速览：本机的“防误退”是 ROM 框架级机制，没有设置开关；本 App 已自带绕过方案（装 APK 即生效）。其余儿童组件本机已全部禁用。

## 一、防误退机制（返回键退不出应用）是什么

- ROM 在系统框架里加了 `checkAllowQuitState` / `mIsAllowQuit`：**非系统应用（第三方 App）一律禁止用返回键退出**。
- 实测证据：本 App、Via 浏览器、adbwireless 按返回都退不掉；系统应用（相册）可以退出。
- 日志证据：`isAllowQuit: mIsAllowQuit=false`。
- 设置库 / 系统属性 / 相关应用数据里**没有可关闭它的开关**（已逐一排查）。

## 二、本 App 的解决方案（随 APK 自带，重置后装 APK 即生效）

代码在 `app/src/main/java/com/magneo/compass/BaseActivity.java`：

1. 覆写 `dispatchKeyEvent`：返回键按下时直接 `finish()` 并吞掉事件，完全绕开框架的防退检查路径；
2. `QuitFix`（反射）兜底把框架字段 `mIsAllowQuit` 置为 `true`；
3. 所有页面继承 `BaseActivity`，且每个子页面还有罗盘风格“◀ 返回”按钮。

验证：装好 APK 后，任意页面按**物理返回键**应能正常退出回到罗盘主屏。

## 三、如果想让“其他第三方应用”也能按返回退出

ROM 层无开关，可选方案（按需，不必做）：

**Magisk 模块法（推荐，系统级生效、可整模块卸载）**
```bash
adb push 你的应用.apk /sdcard/app.apk
adb shell "su -c '
mkdir -p /data/adb/modules/backfix/system/app/YourApp
cp /sdcard/app.apk /data/adb/modules/backfix/system/app/YourApp/YourApp.apk
chmod 644 /data/adb/modules/backfix/system/app/YourApp/YourApp.apk
'"
adb reboot
# 卸载原 /data/app 版本，避免与系统副本冲突：
adb shell pm uninstall -k --user 0 <包名>
```
原理：放进 `/system/app` 后 PackageManager 会把它标记为系统应用，框架的防退检查对系统应用放行。

**直接拷贝 /system/app（不推荐）**：`mount -o rw,remount /system` 后拷贝，改动分区、恢复出厂才会还原，风险高。

## 五、重置系统后的操作清单

1. 开机联网，先装 Magisk 完成 root；
2. 开启 adb（开发者选项/网络调试，或 adbwireless，地址 192.168.31.12:5555）；
3. `adb install -r app-debug.apk`（本 App 自带防退修复，不需要改系统）；
4. 可选：应用内“设置 → 设为默认桌面”；
5. 如需其他三方应用可返回退出 → 按第三节；
6. 儿童组件出厂即禁用；若恢复出厂后又被启用 → 按第四节命令再禁用。

## 六、验证

- 打开内置浏览器 → 按物理返回键 → 应回到罗盘主屏；
- 设置/网盘/灵眼等页面同样验证；
- 界面上每个子页面左上角“◀ 返回”按钮始终可用。

## 四、卸载后台疯狂运行的 NeoBear 全家桶（必做，防卡顿/掉线/自动重启）

本机出厂预装了一批 NeoBear/HelYtech 后台应用，会**在后台持续联网下载、推送、采集应用列表**，
导致整机 CPU 长期满载、反复 ANR（应用无响应）、系统自动杀进程（我们的罗盘 App 和 SystemUI 都会被连累），
严重时表现为：推流/语音时 App 突然退出、设备自动重启、网页设置无响应。

**已确认并已卸载的后台疯狂应用**（2026-08-01）：

| 包名 | 说明 | 后台行为 |
|---|---|---|
| com.neobear.appstore | MAGNEO 应用商店 | 后台下载 APK，CPU 长期 20%+，反复 ANR |
| com.neobear.videochat | 视频通话 | 融云 IM/推送服务常驻联网 |
| com.neobear.logservice | 日志服务 | 小米推送 + 日志采集常驻 |
| com.neobear.parentmanage | 家长管理 | 后台采集应用列表（儿童机制相关） |

**重置系统后一键清理命令**（联网状态下执行）：

```bash
adb connect <设备IP>:5555
adb shell pm uninstall -k --user 0 com.neobear.appstore
adb shell pm uninstall -k --user 0 com.neobear.videochat
adb shell pm uninstall -k --user 0 com.neobear.logservice
adb shell pm uninstall -k --user 0 com.neobear.parentmanage
```

验证：`adb shell dumpsys activity services | grep neobear` 应无输出；
`adb shell top -n 1` 里不应再看到 neobear 进程。
